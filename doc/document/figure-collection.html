HOW TO USE

      
사용 방법

    

    

      

        
1. 이 사이트는 뭔가요?

        
이 시스템은 예약구매 · 배송 일정 관리 전용입니다. 상시 판매 중인 상품을 재고처럼 정리하는 용도가 아닙니다.

        
기획 의도는 두 가지입니다.

        
    
          
  • "이번 달엔 뭐가 오지?"를 한눈에 파악하기 — 예약 상품을 여러 개 구매하다 보면 "9월엔 몇 개가 오지? 10월엔?"처럼 배송월별로 헷갈리기 쉬운데, 배송예정월 기준으로 모아보고 필터링해서 한눈에 확인할 수 있게 합니다.
    • 
          
  • 예약마감일을 놓치지 않기 — 마감일이 다가오는 항목은 깜빡임과 임박 알림 모달로 미리 알려줘서, 결제 · 예약 타이밍을 놓쳐 품절되는 걸 방지합니다.
    • 
        

      

      

        
2. 시작하기 — JSON 업로드

        
처음 진입하면 JSON 업로드 모달이 강제로 뜹니다. 파일을 올리기 전까지는 다른 화면으로 넘어갈 수 없습니다.

        
헤더의 "⟲ 데이터 교체" 버튼으로 언제든 다른 JSON으로 바꿔치기할 수 있습니다 (✕ 버튼 · 배경 클릭 · ESC로 취소 가능).

      

      

        
3. 전체 보기 탭

        
전체 / 구매완료 / 미구매 탭으로 구분해서 봅니다.

        
장르 · 스타일 · 배송월 필터와 정렬(기본은 "예약 빠른순" = 예약마감일이 가까운 순)을 쓸 수 있습니다.

        
카드에는 예약마감일 · 배송예정월 · 가격이 표시되고, 카드를 클릭하면 구매 링크로 이동합니다.

      

      

        
4. 미구매 탭 전용 기능

        
    
          
  • 깜빡임 — 예약마감일이 2개월 미만 남으면 카드의 마감일 숫자가 깜빡입니다.
    • 
          
  • 임박 알림 모달 — 예약마감일이 1개월 미만 남은 항목이 있으면, 미구매 탭에 들어갈 때마다 "곧 품절될 가능성이 높은 제품이 있어요!" 모달이 자동으로 뜹니다. "새로고침 전까지 다시 보지 않기" 체크박스로 세션 동안만 끌 수 있습니다.
    • 
          
  • 구매완료 처리 모드 — 버튼을 눌러 켜면 카드에 체크 선택이 생깁니다. 여러 개를 골라 하단 액션바에서 "선택 항목 구매완료 처리 + JSON 다운로드"를 누르면 한 번에 구매완료로 바뀌고 새 JSON이 저장됩니다.
    • 
        

      

      

        
5. 데이터 추가 탭

        
폼으로 새 굿즈 정보를 입력합니다. ID는 자동 부여됩니다.

        
배송예정월을 고르면 예약마감일(한 달 전 말일)이 자동으로 채워지며, 수동으로 수정할 수도 있습니다.

        
우측 JSON 패널에서 현재 데이터를 실시간으로 확인 · 다운로드할 수 있습니다.

      

      

        
6. 데이터 삭제 탭

        
전체 / 구매완료 / 미구매로 필터링해서 원하는 항목만 찾아 ✕ 버튼으로 삭제합니다.

      

      

        
7. 저장 방식 주의사항

        
이 앱은 서버 없이 브라우저 메모리에서만 동작합니다. 추가 · 삭제 · 구매완료 처리는 화면에 즉시 반영되지만, 새로고침하면 사라집니다.

        
변경사항을 남기려면 반드시 "JSON 다운로드"로 파일을 받아서, 다음에 그 파일을 다시 업로드해야 합니다.
